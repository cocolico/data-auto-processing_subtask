# 多视角标注检查与可视化 SDK

在控制台左侧选择「结果预览」，选择已完成的 Episode，点击「打开结果」。本页只读取现有视频和标注，不触发模型调用，也不修改训练数据。

## 本机检查界面

- 同屏显示 cam0 外部总览、cam1 右手腕、cam2 左手腕。选择「突出显示」可放大任一路，另外两路继续显示。
- 三路共享播放 / 暂停、速度、时间滑块。缓冲或跳转时等待可用视角就绪；播放时校正视角时间差，并显示时间差毫秒数。浏览器视频同步属于尽力对齐，不能替代数据集帧时间戳的严格校验。
- 使用「−1 帧 / +1 帧」或方向键检查边界，时间以原数据集帧率换算。帧编号从 0 开始，片段使用左闭右开区间 `[start_frame, end_frame)`。
- 点击粗阶段、细动作色块或步骤序号跳到片段起点。勾选「循环当前片段」后反复播放当前选定片段；切换片段会更新循环范围。
- 右侧显示当前动作的英文训练指令、细分类别、粗阶段、起止时间、帧范围、目标 ID、决策和放回条件。下方明细支持按动作类别筛选。
- 七类动作用固定颜色区分。颜色只表示动作类别；当前协议没有模型置信度字段，界面不展示推测的置信度。END 在细粒度时间轴保留，粗粒度未映射部分显示为空灰色。
- 每路独立提示视频是否可用。视频已释放时仍可定位和查看文字标注；任一路失败不会让另外两路消失。离开预览页或切到后台时暂停视频。

## 可选安装

基础三路预览不依赖 Rerun 或 Foxglove，也不需要 Node、云端账号或联网资源。专业文件导出是可选功能，在运行 GUI 的同一个 Python 环境安装：

```bash
.venv/bin/python -m pip install -e '.[annotation,visualization]'
```

安装后正常停止并重新启动 GUI。预览页底部会分别显示 SDK 是否就绪；缺少 SDK 时对应导出按钮禁用。

本次实际验证的版本为 `rerun-sdk==0.42.0` 和 `foxglove-sdk==0.30.3`。可选依赖在 `pyproject.toml` 中定义，不会自动扩大现有迁移安装脚本的安装范围。

## Rerun / Foxglove 导出

点击「导出 Rerun · RRD」或「导出 Foxglove · MCAP」。文件由单独的本机进程后台生成，同一时间只生成一个文件。完成后点击下载链接，在相应查看器中打开。

- Rerun：`.rrd` 包含三路图像、动作边界日志、随时间更新的当前标注文档，以及完整标注元数据。预设布局包含图像与标注文档。使用与 SDK 相同版本的 Rerun 查看器打开，例如 `rerun annotation.rrd`。
- Foxglove：`.mcap` 使用官方 Foxglove SDK 的 `CompressedImage` 通道，三路分别为 `/cameras/cam0`、`/cameras/cam1`、`/cameras/cam2`。添加三个 Image 面板选择对应通道，再添加 Raw Messages 面板选择 `/annotations/steps`，按时间联合核对画面与标注。`annotations.json` 附件保留完整粗细标注。
- 专业导出默认按 **2 fps** 采样，额外保留每个细动作起点和最后一帧；所有标注边界仍按原始帧编号保存。导出画面最长边受 640×480 预览框限制，使用 JPEG 压缩。专业导出用于浏览，不替代页面上对原视频的逐帧检查。
- 时间原点为当前 Episode 的 0 秒；三路画面不会顺序拼接，也不会把采样视频伪装成完整 30 fps。
- 「下载标注 JSON」不依赖 SDK，即使本机视频已释放也可使用。

导出保存在当前标注运行目录的 `viewer-exports/<job>/<内容签名>/`。相同输入直接复用已有文件；不同输入使用不同签名。单文件限制为 512 MiB，可用磁盘不足 512 MiB 时停止生成，最长运行时间 15 分钟。失败的临时文件不会作为成品提供下载。关闭 GUI 不影响原始标注和生产交付。

导出视频沿用现有任务范围和相机白名单检查；启动导出需要本机请求令牌，下载也需令牌。没有外部网页嵌入、模型调用或自动云端上传。

## 验证范围

本次使用合成三路视频与明确标记的演示标注检查播放、逐帧定位、片段循环、相机焦点、动作筛选和两种 SDK 导出。RRD 已通过官方 `rerun rrd verify` 校验；MCAP 已读回三路通道、消息数与非采样网格上的动作边界。自动化测试同时覆盖后台生成、未授权源路径、下载令牌、Range 响应及失败时不发布临时文件。

真实模型标注质量需要使用实际 Episode 另行评估；界面改进不等同于已经验证识别准确率。
